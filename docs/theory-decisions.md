# Theory decisions

Every `THEORY-DECISION:` in code or spec gets an entry here. The owner reviews `open`
entries and sets them to `approved` or `changed`.

| # | Decision | Rationale | Where | Status |
|---|---|---|---|---|
| 1 | Major key set uses Gb, not F# | Jazz lead-sheet convention | `apps/web/src/theory/keys.ts`, ARCHITECTURE § 3.2 | open |
| 2 | A *chromatic* root (numeral with `b`/`#`) that would need a double accidental is respelled enharmonically (fewest accidentals, flats on tie): `bII:7` in Gb → G7, in Db → D7. Diatonic roots are never respelled: `vii:dim7` in G# minor = F##dim7 | Lead sheets never write Abb7; respelling a diatonic root would break functional spelling. Chord tones keep strict letter arithmetic | `apps/web/src/theory/roman.ts`, ARCHITECTURE § 3.5 | open |
| 3 | `any` preset: only the literal `5` is optional; `b5`/`#5` stay required | Altered fifths define dim/aug/m7b5 | `apps/web/src/evaluation/presets.ts` | open |
| 4 | `shell` and `inversion_3` are rejected at build time for triads; `shell` on 6-chords uses `6` as the "7th" | Shell needs a 7th; triads have no 3rd inversion | `apps/web/src/evaluation/presets.ts` | open |
| 5 | Tension table for `extras: allowTensions` (e.g. dom7: b9 9 #9 #11 b13 13; m7: 9 11 13; maj7: 9 #11 13; m7b5: 9 11 b13; dim7: 9 11 b13 7) | Common jazz-pedagogy tension sets; not used by any M1 preset | `apps/web/src/evaluation/tensions.ts` | open |
| 6 | Rootless voicings on 6-chords use only `5` in the "5/13" slot (the 6 is the "7th" slot) | Avoids a duplicate pitch class | `apps/web/src/evaluation/presets.ts` | open |
| 7 | Single-accidental chromatic roots are kept: `bII:7` in Eb = **Fb7** (not E7) | Owner: Fb7 is closer to the theory (bII of Eb is an F-letter chord); only double-accidental roots are respelled | `apps/web/src/theory/roman.ts` | approved |
| 8 | 7sus4: the "3rd" slot is `4` for `inversion_1`, `shell` (1-4-b7) and `guide_tones` (4-b7). Rootless A/B on 7sus4 is rejected | `4` takes the 3rd's role in sus chords. Rootless sus voicings are a different shape (b7-9-11-13), so the 3-7-9 template doesn't apply | `apps/web/src/theory/chords.ts` (`thirdOf`), `apps/web/src/evaluation/presets.ts` | approved (owner); rootless exception open |
| 9 | `guide_tones` on triads is rejected (PresetError), like `shell` | No 7th to guide | `apps/web/src/evaluation/presets.ts` | open |
| 10 | A played note whose pitch class is not in `tones` (and not an allowed tension) is reported as `unexpected`, never as a forbidden degree | `forbidden` only lists tokens the spec names explicitly | `apps/web/src/evaluation/match.ts` | open |
| 11 | Progression runner: a committed mismatch only counts if the same note set settled while the current chord was expected | Releasing the just-accepted chord must not count against the next one | `apps/web/src/evaluation/runner.ts`, ARCHITECTURE § 4.5 | open |
| 12 | Triad drills (`triads-major`, `triads-minor`) require the 5th, overriding the `any` preset where 5 is optional | A lesson about building triads must not accept C–E as "C major"; dim/aug already require their altered 5th | `content/exercises/triads-*.yaml` | open |
| 13 | Blues scale is spelled 1 – ♭3 – 4 – **♭5** – 5 – ♭7 (C blues: C E♭ F **G♭** G B♭), not ♯4/♯11 | Most lead sheets and method books write the blue note as ♭5; one spelling both ways. Consequences: E♭ blues has **B𝄫**, B♭ blues **F♭**, F blues **C♭** (many books write E♭ blues with A♮). ♯4 would be worse (C♯ blues: F𝄪, G♯ blues: C𝄪) | `content/exercises/scale-blues.yaml` | open |
| 14 | Half-diminished and diminished seventh drills use the minor key set (G♯, C♯, F♯ instead of A♭, D♭, G♭) | Keeps roots readable: G♯m7♭5 (G♯ B D F♯) instead of A♭m7♭5 (A♭ C♭ E𝄫 G♭); G♯°7 instead of A♭°7 with G𝄫. Still strict letter arithmetic, so E♭°7 = E♭ G♭ **B𝄫 D𝄫**, B♭°7 = B♭ D♭ F♭ **A𝄫**, E♭ø7 has **B𝄫**, B♭ø7 has **F♭**. D♯°7/D♯ø7 would need a third key set (known limitation) | `content/exercises/sevenths-half-diminished.yaml`, `sevenths-diminished.yaml` | open |
| 15 | Minor ii–V–i resolves to **m7** (e.g. Dm7♭5 – G7 – Cm7) | The most common lead-sheet choice (e.g. Autumn Leaves); m6 and m(maj7) tonics are equally idiomatic and could become variants. Known limitation: the idiomatic minor V is V7(♭9), but `voicing: any` forbids extras, so G7♭9 in C minor is marked wrong | `content/exercises/ii-v-i-minor.yaml` | open |
| 16 | Triad progressions (`cadence-i-iv-v-i`, `pop-i-v-vi-iv`, `andalusian-cadence`, `fifties-i-vi-iv-v`, `diatonic-triads-ladder`) use `voicing: any`, where the 5th is optional, so root + third counts as the chord | Matches the existing progression drills; unlike the single-triad drills (#12) they are about chord changes, not building the triad | `content/exercises/*.yaml` | open |
| 17 | "Root in bass" setting (header toggle, default off): it only switches the bass rule of the `any` and `root_position` presets (on = root in the bass, off = any inversion; tones unchanged). Inversion, shell and rootless presets and an explicit `constraints.bass` keep their own bass. Lessons can force it per exercise (`rootPosition={true\|false}`); the triads, cadence and pop lessons force it off because they teach inversions | The bass is the point of inversion drills; root-position drills taught chord construction, which the player can now opt into. Default off: jazz pianists rarely voice chords in root position. Changes what `dominant-seventh-roman` (root position) accepts unless the toggle is on | `apps/web/src/exercises/play_chord/resolve.ts` | open |
| 18 | The circle-of-fourths chains (`circle-of-fourths-*`, key C) spell the bottom of the circle **G♭** (`bV`), then continue B, E, A, D, G | Lead sheets cycle C F B♭ E♭ A♭ D♭ G♭ B …; F♯ is the equally valid enharmonic. The chains are only offered from C, since other start keys would just respell the same lap (e.g. C♭ instead of B from F) | `content/exercises/circle-of-fourths-*.yaml` | open |
